Bg-removal is a versatile image editing tool built with the MERN stack. This application allows users to upload an image, process it using AI to remove the background and download the image with a transparent background. The app also includes a credit system for background removal and integrates an online payment method for purchasing more credits.

## Features

- **AI-Powered Background Removal**: Upload an image and let our AI process it to remove the background seamlessly.
- **Credit System**: Manage your credits for background removal. Purchase more credits using the integrated online payment method.
- **User Authentication**: Secure user authentication and management using Clerk.
- **Responsive Design**: Optimized for both desktop and mobile devices.

## Tech Stack

- **Frontend**: React, JavaScript, HTML5, CSS3
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Authentication**: Clerk

## Getting Started

### Prerequisites

- Node.js
- MongoDB

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Besufekad-HAZ/Background-Removal-App.git
   cd Background-Removal-App
   ```
2. Install dependencies:
 ```bash
   npm install
   ```
3. Set up environment variables: Create a .env file in the root directory and add the following:

MONGODB_URI=your_mongodb_uri
CLERK_API_KEY=your_clerk_api_key
PAYMENT_API_KEY=your_payment_api_key

4. Start the development server:

   ```bash
   npm run dev
   ```
5. To run the tests, run the following command:
   
```bash
  npm test
```

### Deployment

You can deploy this project using:
```
   npm run build
```
